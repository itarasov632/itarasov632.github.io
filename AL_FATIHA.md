# Обучение Аль-Фатихе

Страница: `/pages/al-fatiha.html`. Вход с главной страницы и из списка сур; старая ссылка `/pages/surah.html?id=1` направляет на обучение, поскольку в main отсутствуют изображения и аудио Аль-Фатихи.

В `media/al-fatiha/` опубликованы только восемь объяснений и чтение всей суры: 67 904 609 байт видео (67,90 МБ), плюс постеры и manifest.json. Совет исключён из публичного manifest, файлов и интерфейса. Исходная OBS-запись и монтажные проекты не добавлены в Git.

`manifest.json` — источник текста, порядка, привязки к аятам, таймкодов OBS и параметров файлов. Нумерация включает басмалу как 1:1; фрагменты 7 и 8 — части одного аята 1:7. Сверка текста и нумерации: https://quran.com/al-fatihah. Навигационные русские подписи не являются транскрипцией.

## Загрузка и размещение

При входе загружаются HTML/CSS/JS и manifest, без MP4 и без всех постеров. При выборе создаётся один video с preload=none и playsinline; MP4 запрашивается при запуске. При переключении и уходе со страницы прежний источник освобождается. Соседние клипы не предзагружаются. Новый service worker не регистрируется; в офлайн-кеш видео не добавляются. URL медиа содержит префикс SHA-256, обновляйте manifest при замене файлов.

Текущее размещение — существующий GitHub Pages из main. Объём укладывается в ограничение опубликованного сайта 1 ГБ; внешний сервис сейчас не нужен. Мягкий лимит трафика GitHub Pages — 100 ГБ/месяц: примерно 1470 полных загрузок девяти видео без учёта остальных ресурсов и повторного просмотра. При росте аудитории потребуется пересмотреть размещение. Источник: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits (проверено 2026-11-02).

## Проверки 2026-11-02

- Браузер Chromium, viewport 390×844: список, арабский текст и просмотр, без горизонтального переполнения на просмотренных экранах.
- Все 9 видео запускаются и возвращают ожидаемые длительности; проверены пауза, +10/−10 секунд, повтор с начала, следующий фрагмент, полноэкранный просмотр, возврат к списку (video удаляется), старая ссылка.
- Ошибка загрузки проверена временным отключением одного локального MP4; после восстановления кнопка повторной загрузки запускает видео.
- Журнал локального HTTP-сервера: при входе нет MP4-запросов; при выборе до воспроизведения загружается только постер. При воспроизведении идут Range/206-запросы выбранного ролика.
- Размеры и SHA-256 всех девяти скопированных MP4 совпадают с исходным manifest; JS проходит node --check, diff проходит git diff --check.
- На физическом iPhone и в Safari не проверено. Полное ручное прослушивание всех уроков не проводилось. H.264/AAC MP4 и fast start сохранены из подготовленных материалов.
