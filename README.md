# Второй учитель - PWA приложение

Приложение для изучения арабского алфавита с произношением и правилами таджвида, а также краткие суры.

## Особенности
- PWA (Progressive Web App) - работает офлайн
- Оптимизировано для iOS
- Реальное произношение букв
- Изображения махраджа (мест произношения)

## Установка для разработки
1. Клонируйте репозиторий
2. Откройте index.html в браузере
3. Для PWA: добавьте на домашний экран iOS

## Структура проекта
- `/pages` - HTML страницы
- `/css` - Стили
- `/js` - JavaScript модули
- `/assets` - Ресурсы (изображения, аудио)

## Развертывание
Просто загрузите файлы на любой статический хостинг (GitHub Pages, Netlify, Vercel).

## Прозрачность изображений
Рисунки и изображения текста используют прозрачный PNG-фон. Скрипт
`python scripts/transparent_backgrounds.py` убирает только бумажный фон,
сохраняя исходные RGB-пиксели и размеры. Проверка:
`python scripts/transparent_backgrounds.py --verify` (Pillow и numpy).
Постеры видео и текстура `assets/images/watercolor/paper.png` сохранены.
Сборщики карточек и сканов также применяют эту обработку; манифесты хранят
хеш исходного RGB-файла и хеш итогового PNG с прозрачностью.
